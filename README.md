🎬 Movie Ticket Booking Calculator

A beginner-friendly Python-based Movie Ticket Booking Calculator that demonstrates how different booking conditions can be handled using conditional statements.

The program checks the user's age, show time, membership status, weekend status, seat type, and other booking conditions before determining whether the ticket can be booked and calculating applicable charges.

✨ Features

- 🎟️ Checks whether the user is eligible to book a movie ticket
- 🌆 Checks eligibility for evening shows based on age
- 👤 Provides membership discount when applicable
- 📅 Handles weekend conditions
- 💺 Supports different seat types such as:
  - Premium
  - Gold
  - Regular
- 💰 Calculates additional charges based on seat type
- ⚠️ Prevents booking when restrictions are not satisfied
- 🧮 Demonstrates basic calculation and decision-making in Python

🛠️ Technologies Used

- Python
- Variables
- "if", "elif", and "else" statements
- Boolean values
- Conditional logic
- Basic arithmetic operations
- "print()" statements

🔄 How the Program Works

The program follows a simple booking flow:

1. Sets the base ticket price.
2. Checks the user's age.
3. Determines whether the user is eligible to book a ticket.
4. Checks eligibility for an evening show.
5. Checks membership status and applies a discount if eligible.
6. Checks additional booking conditions.
7. Calculates extra charges.
8. Determines service charges based on the selected seat type.
9. Displays the booking result and applicable charges.
